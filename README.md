# bank-ai-antifraud-dlp-lab1
Eight-layer security architecture protecting synthetic banking transaction data from internal and external AI-agent risks(писание: > Учебная архитектура восьмиуровневой защиты синтетических банковских транзакционных данных от внутренних и внешних ИИ-агентов.)
## Цели проекта

- моделирование антифрод-контролей;
- защита чувствительных данных;
- контроль доступа AI-агентов;
- DLP-маскирование;
- контроль исходящих каналов;
- мониторинг и реагирование на инциденты.

## Ограничения

Проект использует только синтетические данные и не подключается к реальным банковским системам.
